# Cape

> Cape is a privacy-first U.S. mobile carrier (MVNO) that runs its own mobile core and SIMs on leased tower infrastructure, adding privacy-enhancing controls such as daily identifier rotation, minimal data collection, disappearing call logs, SIM-swap protection, and secure global roaming. Cape serves privacy-conscious consumers, enterprises, and government agencies. Cape publishes no public developer API; this profile is an API Evangelist network company record.
